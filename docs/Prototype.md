# 튜토리얼 레벨 프로토타입 (v0.1)

> 작성일: 2026-09-09
> 대상: `SimpleGame` OpenGL 프로젝트를 수정해 만든 첫 플레이 가능 빌드.
> 배경 문서: [GameDesignDoc.md](GameDesignDoc.md), [GameConcept.md](GameConcept.md)

물안개 마을, 포자가 막 도착한 아침. 기획서 7절 튜토리얼의 6~7단계 지점을 잘라
플레이 가능한 형태로 만든 것이다. 할머니를 찾고, 편지를 읽고, 마을을 떠난다.

---

## 1. 요구사항 대응

| # | 요구사항 | 구현 | 위치 |
|---|---|---|---|
| 1 | WASD 조작 | 카메라 기준 이동. 방향키도 같은 입력으로 동작 | `Game::UpdatePlayer`, `SimpleGame.cpp` |
| 2 | 스페이스바 대쉬/구르기 | 0.28초 구르기, 쿨다운 0.7초. 구르는 동안 몸이 앞으로 한 바퀴 돌고 포자 노출이 멈춘다 | `Game::OnKeyDown`, `Game::UpdatePlayer`, `Game::DrawPlayer` |
| 3 | 2.5D 쿼터뷰 | 직교 투영 고정 카메라. 요 45°, 피치 30°, 세로 20유닛 | `Game::Render` |
| 4 | 분위기 렌더링 | 시간대별 색온도, 높이 감쇠 지수 안개, 포자 파티클 7000개, 저채도 그레이딩, 비네트·헤이즈, 절차적 지면, 물결 수면 | `Shaders/*`, `Game::MakeEnv` |
| 5 | 작은 퀘스트 | 3단계 메인(할머니 → 편지 → 마을 밖) + 선택 수집(꿈 조각) | `Game::TryInteract`, `Game::ObjectiveText` |
| 6 | 포자에 둘러싸인 마을에서 시작 | 시작 시각은 새벽 직후, 포자 밀도 최대, 노출 게이지 0.15에서 시작 | `Game` 생성자, `Game::SporeDensityNow` |
| 7 | 막 잠든 마을 사람들 | 5명. 누운 자세로 호흡하며 이끼가 돋는다. 곁에서 쉬면 꿈 조각 | `Game::BuildWorld`, `Game::DrawSleepers` |
| 8 | OpenGL 프로젝트 수정 | 기존 `SimpleGame.vcxproj`에 파일 추가. 새 솔루션을 만들지 않음 | `SimpleGame.vcxproj`, `.filters` |

## 2. 조작

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (화면 기준. W가 항상 화면 위쪽) |
| Space | 구르기 |
| E | 상호작용 / 편지 닫기 |
| T | 시간 흐름 12배 토글 (데모용. 하루를 20초에 본다) |
| ESC | 종료 |

## 3. 퀘스트 흐름

1. **할머니를 찾는다.** 마을 북쪽 집 앞에 순임이 누워 있다. E를 누르면 손끝의 이끼와 옆의 편지를 확인한다.
2. **편지를 읽는다.** 편지 패널이 열린다. 내용은 기획서 3.1절의 편지 그대로다.
3. **마을을 떠난다.** 남쪽 도로(32번 국도 입구, z > 26)를 넘으면 안개가 화면을 덮고 프로토타입이 끝난다.

**선택 요소**: 잠든 마을 사람 4명 곁에서 쉬면 꿈 조각을 얻는다(목표 3개). 꿈 조각은
자연 이해도가 되어 포자 노출 상승 속도를 조각당 18% 낮춘다. 저수지 가장자리
4.5유닛 안에서는 노출이 회복된다.

**실패 없음**: 기획서 7절 원칙대로 포자 노출이 가득 차도 죽지 않는다. 화면이 더
흐려지고 비네트가 조여들 뿐이다.

## 4. 렌더링 구성

| 셰이더 | 역할 |
|---|---|
| `Lit.vs` / `Lit.fs` | 프롭·지면·수면. 모드 0 단색, 모드 1 절차적 지면, 모드 2 수면. 랩 디퓨즈 + 반구 앰비언트 + 높이 감쇠 안개 + 채도 조절 |
| `Particle.vs` / `Particle.fs` | 포자. 정적 시드를 정점 셰이더에서 애니메이션하고 카메라 주변 박스로 랩. 가산 블렌딩 |
| `Overlay.vs` / `Overlay.fs` | 화면 공간. 모드 0 사각형(HUD·페이드), 모드 1 비네트 + 포자 헤이즈 |
| `SolidRect.vs` / `.fs` | 교수 템플릿 원본. 남겨 둠 |

지면은 텍스처 없이 값 노이즈로 콘크리트·흙·이끼·풀을 섞는다. 도로는
`roadCenter(z) = sin(z*0.05)*3` 곡선으로 그려지며, `Game.cpp`의 `RoadCenter`가 같은
식을 써서 표지판 위치를 맞춘다. 자연화 단계 0→1을 한 화면에서 보여주는 것이 목적이다.

시간대 색은 기획서 6절대로 새벽 보라 / 정오 연녹 / 황혼 주황 / 밤 남색 네 키프레임을
보간한다. 하루는 실제 240초다.

## 5. 새 파일과 변경

**추가**
- `SimpleGame/Math3D.h` — Vec3, Mat4, 법선 행렬. 헤더 전용, 외부 라이브러리 없음
- `SimpleGame/Game.h`, `Game.cpp` — 월드 구성, 플레이어, 카메라, 퀘스트, HUD
- `SimpleGame/Shaders/Lit.vs·fs`, `Particle.vs·fs`, `Overlay.vs·fs`

**수정**
- `SimpleGame/Renderer.cpp`, `Renderer.h` — 3D 파이프라인, 파티클, 화면 오버레이, 비트맵 텍스트 추가. 템플릿의 `DrawSolidRect`는 남겨 둠
- `SimpleGame/SimpleGame.cpp` — 1280x720 창, 델타 타임 루프, 키 눌림 상태 배열, 리사이즈 대응
- `SimpleGame/SimpleGame.vcxproj`, `.filters` — 새 파일 등록. **x64 Debug / Win32 Release / x64 Release 링크 목록에 빠져 있던 `opengl32.lib` 추가** (Win32 Debug에만 있었다)

**인코딩**: `Renderer.cpp`의 깨진 CP949 주석을 ASCII 주석으로 교체했다. 새 소스도
전부 ASCII로 작성했다.

**이름 주의**: 텍스트 출력 함수는 `Renderer::DrawTexts`다. `DrawText`로 두면
`windows.h`(freeglut가 끌어온다)가 `DrawText`를 `DrawTextW` 매크로로 바꿔 버려
"'DrawText': 'Renderer'의 멤버가 아닙니다" 컴파일 오류가 난다. 앞으로 추가하는
멤버 함수도 Win32 API와 이름이 겹치지 않게 한다.

셰이더도 마찬가지로 **GLSL 내장 함수·예약어와 이름이 겹치지 않게 한다.** (2026-09-14)
`Lit.fs`의 `float noise2(vec2)`는 내장 함수 `noise2`(반환형 `vec2`)와 충돌해
"overloaded functions must have the same return type"이, 변수 `patch`는 GLSL 4.00
예약어라 `#version 330`에서도 드라이버에 따라 "syntax error"가 났다. 각각
`valueNoise`, `patchMask`로 바꿨다. 셰이더 하나라도 컴파일에 실패하면 해당 오브젝트가
통째로 안 그려져 화면에 클리어 색(시간대 안개색)만 남으므로, 이상하면 콘솔 로그부터 본다.

## 6. 이 프로토타입이 정한 값 [가결정]

기획서 9.2절에서 [미정]이던 항목을 프로토타입이 실제 값으로 정했다. 바꾸기 쉽다.

| 항목 | 값 | 근거 |
|---|---|---|
| 2.5D 구현 방식 | 3D 박스 지오메트리 + 고정 직교 카메라 | 이미지 로더도 스프라이트 애셋도 없다. 박스는 조명·안개·그림자 방향을 그대로 받아 분위기 요구(4번)를 바로 충족한다 |
| 쿼터뷰 각도 | 요 45°, 피치 30° | 2:1 디메트릭(약 26.57°)보다 조금 높아 누운 사람과 지면 연출이 잘 보인다 |
| 카메라 투영 | 직교, 세로 20유닛 | 1유닛 = 약 1미터. 720p에서 36픽셀/유닛 |
| 맵 크기 | 마을 약 60 x 60유닛 | 프로토타입 한정. 여섯 지역 전체 크기는 여전히 미정 |
| 시간 흐름 | 게임 내 하루 = 실제 4분 | 데모에서 네 시간대를 다 보여주기 위한 값 |
| 이동 속도 | 걷기 4.2, 구르기 12.0 유닛/초 | |

## 7. 한계

- **화면 텍스트가 전부 영어다.** freeglut 비트맵 폰트는 ASCII만 그린다. 한글을 넣으려면
  폰트 아틀라스 텍스처와 텍스트 렌더러가 필요하다. 편지 원문(한국어)은 기획서 3.1절에 있다.
- 그림자가 없다. 접지감은 안개와 색으로만 표현된다.
- 충돌은 축 정렬 박스뿐이다. 프롭의 회전은 충돌에 반영되지 않는다.
- 사운드 없음.
- 세이브 없음. 엔딩 후에도 계속 걸어 다닐 수 있지만 상태는 저장되지 않는다.

## 8. 빌드와 실행

Visual Studio 2022에서 `SimpleGame.sln`을 열고 빌드한다. 빌드는 사용자가 직접 한다.

셰이더는 실행 시 상대 경로로 읽는다. `Renderer::ReadFile`이 `./`, `../SimpleGame/`,
`./SimpleGame/`, `../../SimpleGame/` 순으로 찾으므로 Visual Studio에서 실행하든 빌드된
exe를 직접 실행하든 동작한다. 그래도 화면이 검게 나오면 콘솔에 찍히는 셰이더 로딩
로그를 먼저 확인한다.
