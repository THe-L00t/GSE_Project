# 프로토타입 (v0.3)

> 작성일: 2026-09-09 (v0.1) · 갱신 2026-09-14 (v0.2) · 2026-09-21 (v0.3, Actor·씬그래프 구조)
> 대상: `SimpleGame` OpenGL 프로젝트를 수정해 만든 플레이 가능 빌드.
> 배경 문서: [GameDesignDoc.md](GameDesignDoc.md), [GameConcept.md](GameConcept.md)
> **빌드 확인은 사용자가 한다.** 이 문서의 v0.2·v0.3 내용은 코드 기준이며 실기 실행 확인 전이다.

두 레벨로 이어진다.
1. **물안개 마을** — 포자가 막 도착한 아침. 할머니를 찾고, 편지를 읽고, 마을을 떠난다. (v0.1)
2. **32번 국도** — 튜토리얼 다음 레벨. 싸우고, 줍고, 레벨을 올리고 능력치를 배분하는 법을 배운 뒤, 시드로 끝없이 자라는 국도를 걷는다. (v0.2)

## 3. 레벨 흐름

### 3.1 물안개 마을

1. **할머니를 찾는다.** 마을 북쪽 집 앞에 순임이 누워 있다. E를 누르면 손끝의 이끼와 옆의 편지를 확인한다.
2. **편지를 읽는다.** 편지 패널이 열린다. 내용은 기획서 3.1절의 편지 그대로다.
3. **마을을 떠난다.** 남쪽 도로(z > 26)를 넘으면 엔딩 카드가 뜬다. 2.5초 뒤 **[E] 로 32번 국도**에 들어간다.

**선택 요소**: 잠든 마을 사람 4명 곁에서 쉬면 꿈 조각(자연 이해도). 조각당 포자 노출 상승 18% 감소 — 국도까지 이어진다. 저수지 가장자리 4.5유닛 안에서는 노출이 회복된다. **실패 없음.**

### 3.2 32번 국도 — 성장 교육 [가결정]

목표가 순서대로 이어진다. 각 단계는 목표가 이미 충족돼 있으면 바로 넘어가므로 어떤 순서로 플레이해도 멈추지 않는다.

| 단계 | 목표 | 배우는 것 | 설계 |
|---|---|---|---|
| 1 | 녹슨 파이프 줍기 | 아이템 줍기, 무기 | 시작 지점 4유닛 앞 도로 위 |
| 2 | 포자 진드기 3마리 처치 | 공격, 적의 예비동작 | 진드기 3마리 경험치 27 → **레벨 2** (필요 25) |
| 3 | C 로 능력치 배분 | **레벨업 · 스탯 조정** | 능력치 창 팁, 오른쪽 「HOW YOU GROW」 카드 |
| 4 | 이끼 멧돼지 처치 | 구르기 회피, 약초(Q) | 약초가 없으면 옆에 하나 놓는다. 경험치 40 → **레벨 3** (필요 40) |
| 5 | 새 포인트 배분 | 다른 능력치 시도 | 「HOW YOU GROW」 카드 유지 |
| 6 | 자유 탐험 | 청크가 사방으로 자라는 국도 | 원점에서 두 칸 이상 떨어진 청크부터 생성 적 등장 |

- 시작 지점 옆 **등불**: 4.5유닛 안에서 포자 노출 초당 −0.08, 체력 초당 +3. 긴 잠에서 깨어나는 곳.
- 화면 오른쪽 위에 **시드 · 현재 청크 좌표 · 청크 해시 · 생성된 청크 수**를 표시한다.

## 4. RPG 규칙 [가결정]

### 4.1 능력치와 성장

| 능력치 | 1포인트당 | 기본값 |
|---|---|---|
| Strength (힘) | 공격력 +2.2 | 3 |
| Vitality (체력) | 최대 체력 +12 | 3 |
| Agility (민첩) | 이동 속도 +3%, 공격 간격 단축 | 3 |
| Insight (통찰) | 포자 노출 상승 둔화 | 3 |

| 수치 | 식 |
|---|---|
| 다음 레벨까지 경험치 | `10 + 15 × 레벨` (25, 40, 55, …) |
| 레벨업 보상 | 능력치 포인트 +3, 체력 완전 회복 |
| 최대 체력 | `40 + 12 × 체력 + 4 × (레벨 − 1)` |
| 공격력 | `4 + 2.2 × 힘 + 무기(파이프 6)` × 0.9~1.1 |
| 이동 속도 배율 | `1 + 0.03 × (민첩 − 3)`, 공격 중 0.7배 |
| 공격 간격 | `0.55초 / (1 + 0.06 × (민첩 − 3))` |
| 포자 저항 배율 | `1 / (1 + 0.12 × (통찰 − 3))` |

- 능력치 창을 열면 **세계가 멈춘다.** 배분 전후 수치(최대 체력·공격력·이동 속도·포자 저항)를 나란히 보여준다.
- 확정 전에는 A 로 되돌릴 수 있고, 창을 닫으면 확정하지 않은 배분은 취소된다.

### 4.2 전투

- 공격: 앞쪽 부채꼴(약 70°). 사거리 맨손 1.5 / 파이프 2.1. 적을 밀어낸다.
- 피격: 0.6초 무적. **구르기 중에는 맞지 않는다.**
- 적 행동: 대기(집 주변 배회) → 추적 → **예비동작(몸이 붉어진다)** → 공격 → 회복.
  가벼운 적(진드기·허물)은 예비동작 중에 맞으면 공격이 끊긴다. 멧돼지는 끊기지 않고 예비동작 시작 때 돌진 방향을 정한다.

| 적 | 체력 | 피해 | 속도 | 공격 | 경험치 | 드롭 (약초/물/유물) |
|---|---|---|---|---|---|---|
| 포자 진드기 | 18 | 5 | 3.2 | 짧은 돌진 (예비 0.45초) | 9 | 35% / 10% / 5% |
| 허물 | 40 | 9 | 2.2 | 서서 휘두름 (예비 0.7초) | 18 | 30% / 25% / 15% |
| 이끼 멧돼지 | 85 | 14 | 2.6 | 긴 돌진 (예비 0.85초, 사거리 5.5) | 40 | 60% / 20% / 25% |

적 레벨이 1 오를 때마다 체력 +25%, 피해 +20%, 경험치 +30%, 속도 +5%.

### 4.3 아이템

| 아이템 | 효과 |
|---|---|
| 약초 | Q: 최대 체력의 40% 회복 |
| 깨끗한 물 | R: 포자 노출 −0.45 |
| 옛 유물 | 주우면 경험치 +12 |
| 녹슨 파이프 | 주우면 무기 장착 (공격력 +6, 사거리 2.1) |

닿으면 줍는다. 떨어진 드롭은 60유닛 이상 멀어지면 사라진다.

### 4.4 긴 잠 (죽음 대신)

- 체력 0, 또는 포자 노출이 가득 찬 상태에서 체력이 초당 4씩 줄어 0이 되면 **긴 잠**에 빠진다.
- 2.2초 뒤 등불 옆에서 깨어난다. 체력 완전 회복, 노출 0.2, **잃는 것 없음.** 기획서의 「실패 없음」 방향을 따른다.

## 5. 맵 생성 — 청크 [가결정]

| 항목 | 값 |
|---|---|
| 청크 크기 | 24 × 24 유닛. 청크 (cx, cz)의 중심 = (cx × 24, 0, cz × 24) |
| 생성 유지 범위 | 플레이어 청크 기준 반경 2 (5×5) |
| 적·아이템 활성 범위 | 반경 1 (3×3). 반경 2를 벗어나면 정리하고, 돌아오면 다시 등장 |
| 그리기 범위 | 카메라 청크 기준 반경 1 (직교 시야를 덮는다) |
| 월드 시드 | `GameRoute.cpp` 의 `kRouteSeed`. **0 이면 실행마다 새 시드**, 다른 값이면 같은 세계 재현 |

**시드가 정해지는 규칙**
- 원점 (0,0) 청크: `MixSeed(월드 시드)`
- 나머지 청크는 **부모가 하나뿐**이다: 원점 쪽으로 한 칸, `|cx| ≥ |cz|` 이면 x 축을, 아니면 z 축을 먼저 줄인다.
- 자식 시드 = `MixSeed(부모 청크 내용 해시 ⊕ (방향 + 1) × 0x9E3779B97F4A7C15)`
  - 부모가 하나로 정해져 있으므로 **어느 방향으로 걸어 들어와도 같은 청크는 같은 시드**를 받는다.
  - 방향을 섞지 않으면 한 부모에서 자란 네 이웃이 똑같아진다.
- 없는 청크를 요청하면 이미 생성된 조상까지 거슬러 올라가, 그 조상부터 바깥쪽으로 차례로 생성한다.

**청크 내용과 해시**
- 자연화 단계: `1 + 링/3` (30% 확률로 +1, 최대 3). 링 = max(|cx|, |cz|). 원점은 1.
- 소품: `8 + 0~6 + (단계 − 1) × 3` 개. 도로와 원점 공터(반경 9)는 비운다. 서로 겹치지 않게 배치.

| 소품 | 충돌 | 가중치 (단계 1/2/3) |
|---|---|---|
| 나무 | 줄기 | 3 / 4 / 5 |
| 소나무 | 줄기 | 1 / 3 / 4 |
| 덤불 | 없음 | 3 / 3 / 3 |
| 바위 | 있음 | 2 / 2 / 2 |
| 폐허 벽 | 있음 | 2 / 1 / 0 |
| 버려진 차 | 있음 | 1.5 / 0.5 / 0 |

- 적 스폰: **링 2 이상**에서 `0 ~ 1 + 단계` 마리. 허물 55%, 링 3 이상에서 멧돼지 25%, 나머지 진드기. 레벨 `1 + 링/2` (30% +1).
- 아이템: 링 1 이상, 55% 확률로 1개 (약초 60% / 물 30% / 유물 10%).
- 처치한 적은 90초 뒤, 청크가 다시 활성화될 때 재등장. 주운 아이템은 다시 나오지 않는다.
- **청크 해시** = FNV-1a 64비트. 좌표, 단계, 소품(모델·위치·회전·크기), 스폰(종류·레벨·위치), 아이템(종류·위치). 실수는 ×100 후 내림해 양자화한다.
- 지면 셰이더는 청크 단계와 네 이웃 단계를 받아, 경계 쪽으로 갈수록 이웃 단계와 섞어 이음새 없이 자연화 정도가 바뀐다.

## 6. 모델과 캐시

- **도형 6종**: 상자·평면(사각형), 원기둥·원판·원뿔(원), 타원체(타원). 원은 16분할, 타원체는 8×16.
- **레시피**: 모델마다 부품 목록(도형·중심·크기·회전·색·애니메이션 비트). 29종 — 플레이어, 파이프, 잠든 사람 2종, 꿈 조각, 편지, 집 2종, 나무, 소나무, 우물, 트럭, 울타리 2종, 표지판, 바위, 덤불, 폐허, 차, 등불, 적 3종, 아이템 4종(파이프 포함), 그림자, 지면.
- **캐시 파일**: 작업 디렉터리의 `Cache/Models/<이름>.mdl`. 헤더 24바이트(`SGMD`, 버전, **레시피 해시**, 정점 수) + 정점(위치·법선·색·애니메이션, 40바이트).
- **로딩 규칙**: 실행 시 레시피를 해시해 파일 헤더와 비교한다. 같으면 파일만 읽고, 없거나 다르면 테셀레이션해서 파일을 새로 쓴다. 분할 수 같은 설정도 해시에 들어가 바뀌면 자동으로 다시 만든다. 콘솔에 `Models: N loaded from Cache/Models, M built.` 가 찍힌다.
- `Cache/` 는 `.gitignore` 에 들어 있다(생성물).

### Actor 와 씬그래프 (v0.3)

**역할 분담.** Actor 는 자기 값(위치·방향·크기, 충돌 모양, 종류별 상태)을 들고 자기 모습을 그린다.
판정과 규칙(이동 충돌, 적 AI, 공격 판정, 줍기, 상호작용, 퀘스트·교육, 포자 노출)은 `Game` 이
Actor 의 값을 받아 처리하고 결과를 Actor 에 다시 쓴다. Actor 에는 게임 규칙이 없다.

**트리.**

```
Root
├─ worldNode ─ 현재 레벨
│    마을: 소품(집·나무·울타리·우물·트럭·표지판) · 물 · 지면 · 편지 · 잠든 사람(─ 꿈 조각) · 출구선
│    국도: 청크 그룹(─ ChunkActor ─ 청크 소품) · 등불 · 깨어나는 자리 · 아이템 그룹 · 적 그룹
├─ Player ─ Weapon
└─ Camera
```

- **월드 행렬** = 부모 월드 × 로컬(이동 · Y 회전 · 피벗 기준 X 회전 · 크기). 값이 바뀌면 자기와 자손을
  더티로 표시하고, 필요할 때만 다시 계산한다. 구르기·긴 잠 기울기는 플레이어의 로컬 변환에 들어가므로
  자식인 무기가 그대로 따라온다.
- **그리기**: 레이어 순서(지면 → 수면 → 오브젝트)로 트리를 전위 순회한다. 블롭 그림자는 깊이를 쓰지 않아
  지면보다 먼저 그리면 덮이므로, 모든 지면을 먼저 그린다. 그리지 않는 Actor(`IsDrawn` 거짓)는 서브트리째 건너뛴다
  — 청크는 카메라 청크 기준 반경 1 만 그린다.
- **삭제**: `Destroy()` 는 표시만 한다. 질의·그리기는 표시된 Actor 를 건너뛰고, `Game::Update` 끝에
  `SceneGraph::RemoveDestroyed` 가 서브트리째 지운다. 순회 도중에 지워도 안전하다.
- **청크**: `ChunkMap`(시드·생성·해시)은 데이터로 그대로 두고, 청크 Actor 는 그 데이터로 만든다.
  플레이어 주변 5×5 는 매 갱신 만들어 두고, 충돌·그리기도 필요한 청크를 찾아 쓴다. 직전 갱신 이후
  아무도 찾지 않은 청크 Actor 는 버리고, 다시 필요하면 같은 데이터로 다시 만든다.
  청크 Actor 는 원점에 두어 소품이 맵 데이터의 월드 좌표를 그대로 쓴다.
- **Actor 가 아닌 것**: 포자 파티클, 데미지·경험치 팝업, 적 체력바, HUD. 화면 연출이라 판정에 쓰이지 않는다.

**인코딩**: 소스는 전부 ASCII. 프로젝트가 CP949 로 컴파일되므로 한글 주석을 넣지 않는다.

**이름 주의**: 텍스트 출력 함수는 `Renderer::DrawTexts`다. `DrawText`로 두면
`windows.h`(freeglut가 끌어온다)가 `DrawText`를 `DrawTextW` 매크로로 바꿔 버려
"'DrawText': 'Renderer'의 멤버가 아닙니다" 컴파일 오류가 난다. 앞으로 추가하는
멤버 함수도 Win32 API와 이름이 겹치지 않게 한다.

셰이더도 마찬가지로 **GLSL 내장 함수·예약어와 이름이 겹치지 않게 한다.** (2026-09-14)
`Lit.fs`의 `float noise2(vec2)`는 내장 함수 `noise2`(반환형 `vec2`)와 충돌해
"overloaded functions must have the same return type"이, 변수 `patch`는 GLSL 4.00
예약어라 `#version 330`에서도 드라이버에 따라 "syntax error"가 났다. 각각
`valueNoise`, `patchMask`로 바꿨다. 셰이더 하나라도 컴파일에 실패하면 해당 오브젝트가
통째로 안 그려져 화면에 클리어 색(시간대 안개색)만 남으므로, 이상하면 콘솔 로그부터 본다.

**코드 스타일**: 탭 들여쓰기, Allman 브레이스, 주석 최소, 멤버 언더스코어 없음(lowerCamel + 선언부 기본값), CRLF.

## 10. 한계

- **화면 텍스트가 전부 영어다.** freeglut 비트맵 폰트는 ASCII만 그린다. 한글을 넣으려면 폰트 아틀라스 텍스처가 필요하다.
- 그림자는 원형 블롭뿐이다. 실제 그림자 맵은 없다.
- 충돌은 마을은 축 정렬 상자, 국도는 원이다. 폐허 벽처럼 긴 소품은 원으로 근사한다.
- 지면 자연화 블렌딩은 청크 모서리(대각 이웃)에서 약간 어긋날 수 있다.
- 청크 경계를 넘는 소품이 이웃 청크 소품과 겹칠 수 있다.
- 사운드·세이브 없음. 국도에서 레벨을 떠나거나 다시 들어오면 세계는 새 시드로 자란다(`kRouteSeed = 0` 일 때).
- v0.3 구조 변경은 게임 규칙과 화면을 그대로 두는 것이 목표이나, 부동소수 계산 순서가 바뀐 두 곳은
  이론상 최하위 비트 수준으로 다를 수 있다: 무기 행렬(부모 × (이동 × 회전)으로 곱하는 순서), 이웃 청크
  지면이 0.02유닛 겹치는 띠에서 먼저 그려지는 청크. 눈으로 구분되는 차이는 아니다.

## 11. 빌드와 실행

Visual Studio 2022에서 `SimpleGame.sln`을 열고 빌드한다. **빌드는 사용자가 직접 한다.**

셰이더는 실행 시 상대 경로로 읽는다. `Renderer::ReadFile`이 `./`, `../SimpleGame/`,
`./SimpleGame/`, `../../SimpleGame/` 순으로 찾으므로 Visual Studio에서 실행하든 빌드된
exe를 직접 실행하든 동작한다. 화면이 이상하면 콘솔에 찍히는 셰이더 컴파일 로그를 먼저 확인한다.

모델 캐시는 작업 디렉터리 기준 `Cache/Models/`에 만들어진다. Visual Studio에서 실행하면
`SimpleGame/Cache/`, exe를 직접 실행하면 exe 옆이다. 지우면 다음 실행 때 다시 만든다.
