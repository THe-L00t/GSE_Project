### 4.2 전투

## 5. 맵 생성 — 청크 [가결정]

| 항목 | 값 |
|---|---|
| 청크 크기 | 24 × 24 유닛. 청크 (cx, cz)의 중심 = (cx × 24, 0, cz × 24) |
| 생성 유지 범위 | 플레이어 청크 기준 반경 2 (5×5) |
| 적·아이템 활성 범위 | 반경 1 (3×3). 반경 2를 벗어나면 정리하고, 돌아오면 다시 등장 |
| 그리기 범위 (v0.7) | 카메라 청크 기준 반경 3 안에서 **화면에 보이는 청크만**. 땅 직사각형 = 가로 ±(화면 높이/2 × 화면비), 시선 방향 ±(화면 높이/2 ÷ sin 30°). 카메라 쪽 가장자리는 청크의 가장 큰 소품 높이 ÷ tan 30° 만큼 더(키 큰 것이 화면 아래 밖에서 솟아 보이므로). 청크 사각형은 소품이 퍼진 만큼 넓혀 분리축으로 겹침을 본다. 기본 줌에서 보통 12~15개 |
| 월드 시드 | `GameRoute.cpp` 의 `kRouteSeed`. **0 이면 실행마다 새 시드**, 다른 값이면 같은 세계 재현 |

**시드가 정해지는 규칙**
- 원점 (0,0) 청크: `MixSeed(월드 시드)`
- 나머지 청크는 **부모가 하나뿐**이다: 원점 쪽으로 한 칸, `|cx| ≥ |cz|` 이면 x 축을, 아니면 z 축을 먼저 줄인다.
- 자식 시드 = `MixSeed(부모 청크 내용 해시 ⊕ (방향 + 1) × 0x9E3779B97F4A7C15)`
  - 부모가 하나로 정해져 있으므로 **어느 방향으로 걸어 들어와도 같은 청크는 같은 시드**를 받는다.
  - 방향을 섞지 않으면 한 부모에서 자란 네 이웃이 똑같아진다.
- 없는 청크를 요청하면 이미 생성된 조상까지 거슬러 올라가, 그 조상부터 바깥쪽으로 차례로 생성한다.

**청크 내용과 해시**
- 자연화 단계: `1 + 링/3` (링 4부터 30% 확률로 +1, 최대 3). 링 = max(|cx|, |cz|). 원점은 1.
- **시가지 (v0.7)**: 고정 소품 다음, 무작위 소품 전에 짓는다. 도시 정도 `u = 1 − smoothstep(30, 90, max(|x|, |z|))`.
  - 큰길 청크(cx = 0)는 큰길 양쪽 필지 줄, 그 밖 청크는 청크의 위·아래 경계 가로 길을 따라 필지 줄 둘. 줄은 자기 청크 안에서만 채워 이웃 청크와 겹치지 않는다(큰길 줄 뒤 18.5m 까지는 옆 청크가 비워 둔다).
  - 필지 줄은 무작위 폭의 필지를 앞에서부터 채운다(틈 0.3~1.2m). 필지마다 그 자리의 u 로 용도를 고른다. 건물은 길을 정면으로 보고, 큰길에서는 굽은 길에 직각으로 돈다.
  - 건물·담장·가드레일·이정표는 **회전 상자 충돌**(`PushOutOfTurnedBox`). 배치 검사도 원·회전 상자 발자국으로 한다(상자끼리는 분리축).
  - 그다음 큰길 시설(가로등·신호등·차·이정표·가드레일), 링 3부터 집터 묶음.
- 소품: `(8 + 0~6 + (단계 − 1) × 3) × (1 − 0.6u)` 개. 도로(시가지는 인도·가로 길까지)와 원점 공터(반경 9, 시가지 필지는 5.5)는 비운다. 서로 겹치지 않게 배치.

| 소품 | 충돌 | 가중치 (단계 1/2/3) |
|---|---|---|
| 나무 | 줄기 | 3 / 4 / 5 |
| 소나무 | 줄기 | 1 / 3 / 4 |
| 덤불 | 없음 | 3 / 3 / 3 |
| 바위 | 있음 | 2 / 2 / 2 |
| 폐허 벽 | 있음 | 2 / 1 / 0 |
| 버려진 차 | 있음 | 1.5 / 0.5 / 0 |

- **현대성 (v0.5)**: `m = clamp(1 − (링 − 3) / 9, 0, 1)`. 현대 소품(폐허·차·전봇대) 가중치 × m,
  자연 소품 × (1 + 0.5(1 − m)). 도로 칠 × m, 유물 확률 × m. 오른쪽 위 "Old world left" 가 m.
  - v0.7: 자연 소품 × (0.55 + 0.95(1 − m)) × (1 − 0.5u). 농가 물건(경운기·장독대·대문·비닐하우스)과 흔적(집터·빈집·블록 담장·가로등·이정표, 가중치 단계별 1.2/0.8/0.3 · 0.7/0.4/0.1 · 1.0/0.7/0.3 · 0.8/0.5/0.2 · 0.2/0.15/0.05)은 × m × (1 − u).
- **랜드마크 (v0.5)**: (0,2) 버스 정류장, (1,4) 저수지 둘레, (0,6) 은행나무 읍내 입구는 고정 소품을 먼저 두고,
  무작위 소품·적은 그 둘레(반경 5 / 8.5 / 11)를 비운다. 고정 소품도 청크 해시에 들어간다.
- 적 스폰: **링 2 이상**에서 `0 ~ 1 + 단계` 마리. 허물 55%, 링 3 이상에서 멧돼지 25%, 나머지 진드기. 레벨 `1 + 링/2` (30% +1).
- 아이템: 링 1 이상, 55% 확률로 1개 (약초 60% / 물 30% / 유물 10%).
- 처치한 적은 90초 뒤, 청크가 다시 활성화될 때 재등장. 주운 아이템은 다시 나오지 않는다.
- **청크 해시** = FNV-1a 64비트. 좌표, 단계, 소품(모델·위치·회전·크기), 스폰(종류·레벨·위치), 아이템(종류·위치). 실수는 ×100 후 내림해 양자화한다.
- 지면 셰이더는 청크 단계와 네 이웃 단계를 받아, 경계 쪽으로 갈수록 이웃 단계와 섞어 이음새 없이 자연화 정도가 바뀐다.

### Actor 와 씬그래프 (v0.3)

**역할 분담.** Actor 는 자기 값(위치·방향·크기, 충돌 모양, 종류별 상태)을 들고 자기 모습을 그린다.
판정과 규칙(이동 충돌, 적 AI, 공격 판정, 줍기, 상호작용, 퀘스트·교육, 포자 노출)은 `Game` 이
Actor 의 값을 받아 처리하고 결과를 Actor 에 다시 쓴다. Actor 에는 게임 규칙이 없다.

**트리.**

```
Root
├─ worldNode ─ 현재 레벨
│    마을: 소품(집·나무·울타리·우물·트럭·표지판) · 물 · 지면 · 편지 · 잠든 사람(─ 꿈 조각) · 출구선
│    국도: 청크 그룹(─ ChunkActor ─ 청크 소품) · 등불 · 깨어나는 자리 · 아이템 그룹 · 적 그룹
├─ Player ─ Weapon
└─ Camera
```

- **월드 행렬** = 부모 월드 × 로컬(이동 · Y 회전 · 피벗 기준 X 회전 · 크기). 값이 바뀌면 자기와 자손을
  더티로 표시하고, 필요할 때만 다시 계산한다. 구르기·긴 잠 기울기는 플레이어의 로컬 변환에 들어가므로
  자식인 무기가 그대로 따라온다.
- **그리기**: 레이어 순서(지면 → 수면 → 오브젝트)로 트리를 전위 순회한다. 블롭 그림자는 깊이를 쓰지 않아
  지면보다 먼저 그리면 덮이므로, 모든 지면을 먼저 그린다. 그리지 않는 Actor(`IsDrawn` 거짓)는 서브트리째 건너뛴다
  — 청크는 화면에 보이는 것만 그린다(v0.7, 5절 「그리기 범위」).
- **삭제**: `Destroy()` 는 표시만 한다. 질의·그리기는 표시된 Actor 를 건너뛰고, `Game::Update` 끝에
  `SceneGraph::RemoveDestroyed` 가 서브트리째 지운다. 순회 도중에 지워도 안전하다.
- **청크**: `ChunkMap`(시드·생성·해시)은 데이터로 그대로 두고, 청크 Actor 는 그 데이터로 만든다.
  플레이어 주변 5×5 는 매 갱신 만들어 두고, 충돌·그리기도 필요한 청크를 찾아 쓴다. 직전 갱신 이후
  아무도 찾지 않은 청크 Actor 는 버리고, 다시 필요하면 같은 데이터로 다시 만든다.
  청크 Actor 는 원점에 두어 소품이 맵 데이터의 월드 좌표를 그대로 쓴다.
- **Actor 가 아닌 것**: 포자 파티클, 데미지·경험치 팝업, 적 체력바, HUD. 화면 연출이라 판정에 쓰이지 않는다.

**인코딩**: 소스는 전부 ASCII. 프로젝트가 CP949 로 컴파일되므로 한글 주석을 넣지 않는다.

**이름 주의**: 텍스트 출력 함수는 `Renderer::DrawTexts`다. `DrawText`로 두면
`windows.h`(freeglut가 끌어온다)가 `DrawText`를 `DrawTextW` 매크로로 바꿔 버려
"'DrawText': 'Renderer'의 멤버가 아닙니다" 컴파일 오류가 난다. 앞으로 추가하는
멤버 함수도 Win32 API와 이름이 겹치지 않게 한다.

셰이더도 마찬가지로 **GLSL 내장 함수·예약어와 이름이 겹치지 않게 한다.** (2026-09-14)
`Lit.fs`의 `float noise2(vec2)`는 내장 함수 `noise2`(반환형 `vec2`)와 충돌해
"overloaded functions must have the same return type"이, 변수 `patch`는 GLSL 4.00
예약어라 `#version 330`에서도 드라이버에 따라 "syntax error"가 났다. 각각
`valueNoise`, `patchMask`로 바꿨다. 셰이더 하나라도 컴파일에 실패하면 해당 오브젝트가
통째로 안 그려져 화면에 클리어 색(시간대 안개색)만 남으므로, 이상하면 콘솔 로그부터 본다.

**코드 스타일**: 탭 들여쓰기, Allman 브레이스, 주석 최소, 멤버 언더스코어 없음(lowerCamel + 선언부 기본값), CRLF.

## 10. 한계

- **화면 텍스트가 전부 영어다.** freeglut 비트맵 폰트는 ASCII만 그린다. 한글을 넣으려면 폰트 아틀라스 텍스처가 필요하다.
- 섀도맵은 시점 중심 60 × 60유닛만 덮는다. 그 밖은 그림자가 서서히 사라진다(화면 밖이라 보이지 않는 범위).
  밤·새벽에는 태양 고도를 0.30 아래로 내리지 않아, 조명 방향과 그림자 방향이 조금 어긋난다.
- 점광원은 한 프레임 8개까지. 석등이 많아지면 먼 것부터 빠진다.
- (v0.5) 저장이 없어 튜토리얼은 매번 처음부터다(F2 로 건너뛰면 기본 배낭을 준다).
- (v0.5) 국도의 등불 사슴은 소품을 통과해 걷는다(충돌 없음). 저수지로 곧게 간다.
- (v0.5) 은행나무 읍내는 입구까지만 있다. 읍내 안(도현·여울)은 다음 단계.
- 충돌은 마을은 축 정렬 상자, 국도는 원이다. 폐허 벽처럼 긴 소품은 원으로 근사한다.
- 지면 자연화 블렌딩은 청크 모서리(대각 이웃)에서 약간 어긋날 수 있다.
- 청크 경계를 넘는 무작위 소품이 이웃 청크 소품과 겹칠 수 있다(시가지 필지 줄은 자기 청크 안에서만 채워 겹치지 않는다).
- 적은 건물 상자에 밀려나기만 하고 길을 찾지는 않는다. 건물 모서리에 걸려 멈출 수 있다.
- 사운드·세이브 없음. 국도에서 레벨을 떠나거나 다시 들어오면 세계는 새 시드로 자란다(`kRouteSeed = 0` 일 때).
- v0.3 구조 변경은 게임 규칙과 화면을 그대로 두는 것이 목표이나, 부동소수 계산 순서가 바뀐 두 곳은
  이론상 최하위 비트 수준으로 다를 수 있다: 무기 행렬(부모 × (이동 × 회전)으로 곱하는 순서), 이웃 청크
  지면이 0.02유닛 겹치는 띠에서 먼저 그려지는 청크. 눈으로 구분되는 차이는 아니다.

## 11. 빌드와 실행

Visual Studio 2022에서 `SimpleGame.sln`을 열고 빌드한다. **빌드는 사용자가 직접 한다.**

셰이더는 실행 시 상대 경로로 읽는다. `Renderer::ReadFile`이 `./`, `../SimpleGame/`,
`./SimpleGame/`, `../../SimpleGame/` 순으로 찾으므로 Visual Studio에서 실행하든 빌드된
exe를 직접 실행하든 동작한다. 화면이 이상하면 콘솔에 찍히는 셰이더 컴파일 로그를 먼저 확인한다.

모델 캐시는 작업 디렉터리 기준 `Cache/Models/`에 만들어진다. Visual Studio에서 실행하면
`SimpleGame/Cache/`, exe를 직접 실행하면 exe 옆이다. 지우면 다음 실행 때 다시 만든다.
v0.4 에서 레시피와 분할 수가 바뀌었으므로 첫 실행 때 29종이 전부 다시 만들어진다(`M built` = 29).

실행 중 콘솔에 1초마다 `FPS n | Draw calls n` 이 찍힌다(드로우콜은 그 1초의 프레임당 평균,
비트맵 텍스트는 세지 않는다). 목표는 60 FPS 이상.

**v0.6 리소스.** `SimpleGame/Assets/` 의 모델·텍스처는 셰이더와 같은 방식으로 찾는다(`./`, `../SimpleGame/` …).
처음 실행 때 콘솔에서 확인할 줄:
- `Models: 51 from Assets/Models, the rest from shape recipes (...)` — 51 보다 적으면 빠진 모델은 도형으로 그려진다.
- `Ground: Blender layers loaded` — 아니면 지면은 예전 칠한 색.
- `Texture ... not found.` 가 있으면 그 맵만 기본값(흰 바탕·평평한 노멀)으로 대신한다.
- `Lit program does not validate: ...` 가 나오면 셰이더 샘플러 유닛을 확인한다(v0.6 에서 검증을 초기화 끝으로 옮겼다).

리소스를 다시 만들려면 블렌더 5.2 로 `Art/build.py`(하나) 또는 `Art/build_all.py`(전부) — 사용법은 `Art/README.md`.
